    \subsubsection{Analyse}
    De originele visualisatie van de NOS bevat 2 "fouten" namens de principes,
    die in de hoorcolleges zijn behandeld. Er wordt gebruik gemaakt van een 
    \textbf{suboptimaal channel om hoeveelheden te encoderen}, namelijk oppervlaktes.
    Lengtes zijn een effectiever channel om een betere vergelijking te maken. 
    Daarom zou een barchart een betere keuze zijn voor deze data. Hierbij 
    veranderen de marks van vlakken naar lijnen. Om het vergelijken makkelijker
    te maken, worden de bars geordend van groot naar klein en komt de categorie
    "Overig" helemaal onderaan te staan. 

    De kleuren die gebruikt worden om de verschillende categorieën te encoderen
    zijn overbodig, omdat de y-positie van de bars al gebruikt wordt als
    identity channel. Hierdoor is de data-ink ratio suboptimaal. In de titel 
    kan gespecificeerd worden dat de bedragen in miljarden zijn, zodat de
    x-as geen titel nodig heeft en de data-ink ratio verder verhoogd wordt. 

    Een barchart zonder kleur als channel, bevorderd de leesbaarheid. \textbf{
    Een kleurenpallet bestaande uit verschillende tinten van één kleur}, bijvoorbeeld 
    blauw, kan de leesbaarheid verslechteren.

    \subsubsection{Analyse}
     De originele visualisatie van het CBS bevat 2 "fouten" namens de principes,
     die in de hoorcolleges zijn behandeld. \textbf{Er wordt gebruik gemaakt van een 
     suboptimaal channel om hoeveelheden te encoderen}, namelijk grafische tekens.
     Lengtes zijn een effectiever channel om een betere vergelijking te maken.
     Daarom zou een barchart een betere keuze zijn voor deze data. Hierbij 
     veranderen de marks van tekens naar lijnen. Om het vergelijken makkelijker
     te maken, worden de bars geordend van groot naar klein. 
     
     \textbf{Door een vertekende x-as is er sprake van misleiding}. Er is geen consistente
     schaalverdeling, wat ervoor zorgt dat er geinsinueerd wordt dat het lijkt alsof 
     er tussen sommige jaren een grotere groei is dan tussen andere jaren. Dit kan
     eenvoudig opgelost worden door een consistente schaalverdeling te gebruiken.

    \subsection{NOS Europa in cijfers}
    \begin{lstlisting}[language=R]
    {r Inwoners Nederland door de tijd}
    library(ggplot2)
    ggplot(InwonersNederland, aes(x = Year, y = Population)) +
    geom_line(linetype = "dotted") +
    geom_point(size = 3) +
    geom_text(
        aes(label = Population),
        vjust = -0.8
    ) +
    scale_y_continuous(limits = c(0, 20)) +
    scale_x_continuous(
        breaks = seq(1890, 2030, by = 10)
    ) +
    labs(
        title = "Hoeveel inwoners telt Nederland per jaar?",
        x = NULL,
        y = "Inwoners (In miljoenen)"
    ) +
    theme_minimal()
    ggsave("Latex Verslag/src/Grafieken/InwonersNederlandVerbeterd.png", width = 10, height = 10)}
    \end{lstlisting}
